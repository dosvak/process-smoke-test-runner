# Process Smoke Test Runner (PSTR)

Regression checks without leaving the server: a JSON array of test cases (application, process name, input data, expected state, timeout) is started over REST, each instance is polled until it reaches the expected state or the timeout, and the result table shows pass / fail with the elapsed time. Check again re-polls the same instances; Terminate / Terminate and delete clean up.

**Target:** IBM BPM 8.6.2, IBM BAW 20-26 (traditional) and CP4BA (Workflow Authoring / Studio import). Built from out-of-the-box building blocks only (System Data, UI Toolkit, one client-side human service,
server-side service flows calling the product REST API as a technical user) - no third-party toolkit, no custom Java.

## Install

1. Import `packages/Process-Smoke-Test-Runner-1.0.twx` (Process Center / Workflow Center console: *Import Process App*; CP4BA: Business Automation Studio > *Import*).
2. Set the environment variables of the snapshot (below): the server base URL as seen from the server itself and the technical user the
   flows call the REST API with. The package ships no password.
3. Expose the dashboard to a team (the package's default team holds `celladmin`; change it) and open it from Process Portal or the
   playback URL of the human service.

## Dashboard

| Tab | Content |
|---|---|
| Test run | text area with the JSON test cases, Run, Check again, Terminate started instances, Terminate and delete, Export CSV; result table |

## Environment variables

`serverBaseURL`, `restAuthUser`, `restAuthPassword`, `restTrustAllCertificates` (kit-rest.js: the technical user every server-side flow calls the REST API with), `appTitle`, `maxWaitSeconds` (upper bound of a case timeout, default 60).

## Rebuilding and customising

The application is generated by a small Python program on the twxkit generator (standard library only, no base export). The generator
and the kit are served to AI agents and developers by the **BAW Knowledge MCP server** (`https://bawmcp.dosvak.com/mcp`, see
[dosvak/baw-mcp](https://github.com/dosvak/baw-mcp)): `get_package('process smoke test runner (pstr)')` returns this package, `get_tool('build_pstr.py')`
the generator - ask the MCP for the kit apps and it hands out the generator by name.
